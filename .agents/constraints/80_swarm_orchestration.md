# 80 多代理并发协作与工程红线

[上一层：70 Agent 工作环境与凭据安全](70_agent_workspace_and_credentials.md) | [约束索引](README.md)

本层固化经实践验证的多代理并发协作工程不变量（`U32`），适用于并行特性开发、跨模块重构、自动化审计与发布集成全流程。

## §1 契约先行与无交集分片

1. **契约先行（Contract-First）**：并行派发实现任务前，必须先明确跨模块接口、CLI 参数、JSON Schema、错误码区间与文件所有权边界；禁止在接口未定型时并发猜测并各自修改共享契约。
2. **写集严格无交集（Disjoint Write Slices）**：每个并行执行单元必须声明明确的独占写路径清单（文件或目录级）；同一波次内严禁两个并发代理写入同一文件或重叠目录，避免静默覆盖与合并冲突。
3. **指针化精简派单**：任务指令遵循 `50 §1` 的 `L0 -> L1 -> L2` 渐进式披露原则，仅传递精确文件路径、行号范围与验收命令，不在协作消息中重复粘贴整份文档或长段源码。

## §2 读写分离、只读即时审计与路径限定原子提交

1. **只读即时审计（Read-Only JIT Audit）**：代码生成/修改角色与质量审计角色职责分离；每个分片落盘后，由独立只读审计角色基于磁盘真实 `diff`、规范红线与门禁输出进行即时复核，严禁仅凭修改方自述放行。
2. **路径限定原子提交（Path-Scoped Atomic Commits）**：合并与提交必须按已验证分片显式指定路径范围，严禁在并发工作区中盲目暂存全部未跟踪文件或混入其他未验分片的脏改动；提交说明严格遵守 `30 §3` 的 Conventional Commits 1.0.0 格式。
3. **单一集成责任点**：多路分片收口、跨分片一致性校验与统一门禁复跑（`make check` / `tools/check.sh`）由集成角色统一执行，确保合入主分支的每个节点均可独立编译、测试与回滚。

## §3 并发构建隔离与零秘密字面量门禁

1. **Cargo 构建目录与缓存隔离**：多代理或并行作业同时编译/测试 Rust 工作区时，必须为独立任务设置隔离的 `CARGO_TARGET_DIR`（必要时配合独立 `CARGO_HOME`）指向仓库外部 `/tmp` 路径，避免共享 `rust/target` 引发 `.cargo-lock` 争用、`default` 与 `ratatui-ui` 特性产物互踩及 `ETXTBSY` 竞态（呼应 `40 §1`、`60 §1`）；所有构建与测试强制附加 `--locked`。
2. **测试夹具运行期动态拼接**：严禁任何代理在源码、测试夹具、模板或文档中写入可触发 Secret Scanning 的静态秘密字面量；脱敏、拦截与凭据测试必须在运行期动态拼接构造（见 `30 §6`、`70 §3`）。
3. **双层卫生阻断门禁**：分片验收与合入推送前，必须同时通过工作树卫生扫描（`python3 -B tools/verify_repo_hygiene.py`）与全量 Git 历史扫描（`python3 -B tools/verify_repo_hygiene.py --scan-git-history HEAD`），任意命中即刻阻断修复。

## §4 多轮红蓝对抗审查与混沌仿真

1. **多轮红蓝对抗（Multi-Round Red-vs-Blue）**：涉及安全加固、稳态接管（`reconcile`）、凭据管理、安装自举或 TUI 终端状态的高风险改动，须执行多轮红蓝对抗审查——红方独立构造边界注入、非 TTY/断管、权限降级、脏宿主冲突与绕过用例，蓝方最小化修复并补充回归测试，循环收敛直至零高危/严重缺陷残留（呼应 `40 §2`）。
2. **混沌仿真验证（Chaos Simulation）**：关键状态变更链路须在隔离临时环境或容器中验证异常注入场景（部分写入失败、前置检查报错、并发锁冲突、断网降级、重复执行幂等性与快照逐字节回滚），确保故障可观测且不破坏宿主既有自定义配置（见 `60 §3–§4`）。

## §5 外部临时工作区隔离与平台中立

1. **仓库外部 `/tmp` 隔离**：多代理协作规格文档、中间草稿、探测脚本、红蓝对抗日志、混沌仿真夹具与临时构建目录一律存放于仓库外部 `/tmp` 路径（如 `/tmp/debopty-*`），严禁写入仓库目录树或提交至 Git/jj 历史（呼应 `50 §5`）。
2. **平台中立与零日期红线**：所有多代理协作规范、脚本与文档必须保持严格平台中立，严禁混入特定 IDE/厂商私有标识或宿主机绝对调试路径（见 `50 §5`）；`.agents/CONSTRAINTS.md` 与 `.agents/constraints/*.md` 严禁出现具体日期（见 `50 §4`），并持续满足双受众格式契约（见 `00 §5`）。
